# Spec phát triển UniHub

Các tài liệu dưới đây ghi hợp đồng hoàn tiền sandbox và phạm vi cho các mốc tiếp theo. Xem thêm [lộ trình web](../web-development-roadmap.md) và [Phase 4](../microservices-phase-4.md).

1. [Hoàn tiền sandbox và chống hoàn trùng](sandbox-refunds.md) bổ sung thao tác xác nhận cho hàng đợi đối soát của ADMIN.
2. [Thanh toán qua nhà cung cấp](payment-provider-rollout.md) tích hợp cổng thanh toán theo từng môi trường, xác minh kết quả và đối soát.
3. [Kiểm chứng staging và phát hành](staging-release-verification.md) chuẩn hóa cách dựng dữ liệu QA, diễn tập sự cố và ghi bằng chứng nghiệm thu. Việc này có thể bắt đầu song song với mốc hoàn tiền.
